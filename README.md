# EmployeePayrollJDBC

Java JDBC implementation of the Employee Payroll Service learning problem.

---

## 🚀 Technologies Used
- Java
- JDBC
- MySQL
- Maven
- Git & GitHub

---

## 📌 Features (Use Cases)

### UC1 – Connect Java Program to Database
- Establish JDBC connection with MySQL

### UC2 – Retrieve Employee Payroll Data
- Fetch employee data using SELECT query

### UC3 – Update Employee Salary
- Update salary using SQL UPDATE

### UC4 – PreparedStatement for Updates
- Use parameterized queries for security

### UC5 – Retrieve Employees by Date Range
- Filter employees using BETWEEN condition

### UC6 – Calculate Salary Statistics
- Use SUM, AVG, MIN, MAX, COUNT with GROUP BY

### UC7 – Add New Employee
- Insert employee using PreparedStatement

### UC8 – Update Salary Using PreparedStatement
- Clean and safe update method

### UC9 – Retrieve Employees Using Date Condition
- Dynamic date-based filtering

### UC10 – Insert Employee with Start Date
- Multi-column insert with date handling

### UC11 – Insert Employee using Object
- OOP + JDBC integration

### UC12 – JDBC Transactions
- Implement commit & rollback for consistency
